# 🐍 Vivo — Python AI Backend Developer

Repositório destinado ao registro dos **desafios, projetos e exercícios desenvolvidos durante a formação Vivo — Python AI Backend Developer**, oferecida pela [DIO](https://www.dio.me/).

O objetivo deste repositório é documentar minha evolução ao longo da formação, colocando em prática os conceitos apresentados e transformando cada desafio em uma oportunidade para desenvolver **lógica de programação, organização de código e fundamentos de desenvolvimento Backend com Python**.

---

## 🎯 Sobre a Formação

A formação aborda conceitos fundamentais para a construção de aplicações Backend utilizando Python, evoluindo gradualmente dos fundamentos da linguagem para temas como:

* 🐍 Python e lógica de programação
* 📦 Estruturas de dados
* 🧩 Funções e modularização
* 🏗️ Programação Orientada a Objetos
* 🌐 Desenvolvimento de APIs
* 🗄️ Bancos de dados
* 🤖 Inteligência Artificial
* 🔧 Boas práticas de desenvolvimento

## 🧠 Evolução Técnica

Os desafios deste repositório acompanham uma evolução gradual na forma de desenvolver as soluções.

Enquanto os primeiros exercícios têm foco principalmente na **lógica e nos fundamentos da linguagem**, os desafios seguintes passam a explorar:

```text
Lógica de Programação
        ↓
Estruturas de Dados
        ↓
Funções
        ↓
Validação
        ↓
Modularização
        ↓
Persistência de Dados
        ↓
Arquitetura de Aplicação
        ↓
Backend
```

A intenção é não apenas concluir os desafios, mas compreender **por que cada recurso é utilizado e como diferentes partes de uma aplicação podem trabalhar em conjunto**.
