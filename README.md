# DIO — Projetos e Desafios

Repositório destinado aos projetos, desafios e exercícios desenvolvidos durante minhas formações na [DIO](https://www.dio.me/).

O objetivo é registrar minha evolução prática durante os estudos, reunindo projetos desenvolvidos ao longo das formações e aplicando os conhecimentos adquiridos em diferentes áreas do desenvolvimento.

## 📚 Formações

### 🐍 Vivo - Python AI Backend Developer

Formação voltada ao desenvolvimento Backend com Python, abordando fundamentos da linguagem, estruturas de dados, funções, programação orientada a objetos, APIs, bancos de dados, Inteligência Artificial e outros conceitos relacionados ao desenvolvimento Backend.

---

### 🗄️ Formação SQL Database Specialist

Formação voltada ao desenvolvimento de habilidades em bancos de dados relacionais, abordando modelagem de dados, SQL, criação e manipulação de estruturas, consultas e boas práticas para construção de soluções baseadas em necessidades de negócio.

---

## 🛠️ Tecnologias e ferramentas

As tecnologias e ferramentas utilizadas variam de acordo com cada formação e projeto.
