# Projeto E-commerce

Projeto desenvolvido durante a **Formação SQL Database Specialist**, da [DIO](https://www.dio.me/), com foco na modelagem de um banco de dados relacional para um sistema de e-commerce.

## 🎯 Objetivo

Construir um modelo de banco de dados capaz de representar as principais operações de um sistema de e-commerce, aplicando conceitos de:

* Modelagem de dados;
* Modelo Entidade-Relacionamento Estendido (EER);
* Chaves primárias e estrangeiras;
* Cardinalidades;
* Relacionamentos 1:1, 1:N e N:N;
* Tabelas associativas;
* Especialização de entidades;
* Restrições de integridade.

## 🗄️ Modelo

O modelo contempla entidades relacionadas a:

* Clientes;
* Clientes Pessoa Física e Pessoa Jurídica;
* Produtos;
* Fornecedores;
* Vendedores;
* Estoques;
* Pedidos;
* Pagamentos;
* Entregas.

O modelo foi construído e refinado a partir dos requisitos propostos no desafio, buscando representar as regras de negócio de forma consistente.
