# Formação SQL Database Specialist

Formação da [DIO](https://www.dio.me/) dedicada ao estudo de bancos de dados relacionais, modelagem de dados e SQL.

Este diretório reúne os projetos, desafios e exercícios desenvolvidos durante a formação, registrando a evolução prática e a aplicação dos conceitos estudados.

## 🎯 Objetivo

Desenvolver conhecimento prático para:

* Modelar bancos de dados de acordo com necessidades de negócio;
* Identificar entidades, atributos e relacionamentos;
* Definir cardinalidades e restrições;
* Criar e estruturar bancos de dados relacionais;
* Consultar e manipular dados utilizando SQL;
* Aplicar DDL e DML;
* Trabalhar com boas práticas de modelagem e organização;
* Compreender conceitos relacionados à recuperação e controle de concorrência.

## 📚 Conteúdos

A formação aborda, entre outros, os seguintes temas:

* Fundamentos de Banco de Dados
* SGBD
* Modelagem de dados
* Modelo Entidade-Relacionamento
* Modelo Entidade-Relacionamento Estendido (EER)
* SQL
* DDL — Data Definition Language
* DML — Data Manipulation Language
* Consultas e manipulação de dados
* Regras formais de bancos de dados
* Recuperação de dados
* Controle de concorrência

## 🧠 Sobre este repositório

Este repositório não tem como objetivo apenas armazenar as soluções dos exercícios.

A proposta é utilizar cada projeto como oportunidade de prática, buscando compreender **por que determinada estrutura ou solução é utilizada**, revisar as decisões tomadas e aplicar boas práticas ao longo do desenvolvimento.

Os projetos poderão passar por etapas de revisão e refatoração antes de serem considerados concluídos.

> O conteúdo deste diretório será atualizado conforme a formação e os projetos forem avançando.
